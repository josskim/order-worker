# 온채널 로그인 선택자 변경

## 요청

인트라넷의 주문서 수집과 송장 업로드에서 온채널·F온채널 로그인 시 `button.submit-btn` 타임아웃이 발생하는 문제를 수정하고 배포한다.

## 원인

온채널 로그인 화면이 기존 `button.submit-btn` 버튼에서 `#form-login` 내부의 `button[type="submit"]` 구조로 변경되었다. 아이디·비밀번호 입력란의 `name`은 유지되었지만 현재 화면에는 `#login-username`, `#login-password` ID도 사용되고 있었다.

## 변경

- 온채널 공통 로그인 함수를 추가해 현재·구형 입력/제출 선택자를 함께 지원한다.
- 주문서 수집과 송장 업로드가 공통 로그인 함수를 사용하도록 변경했다.
- 온채널 상품 상태·상품 등록도 같은 로그인 경로를 사용하도록 통일했다.
- 로그인 실패 시 화면의 오류 문구를 결과에 포함하도록 보강했다.

## 검증

- Python 컴파일 검사 통과
- 관련 회귀 테스트 20개 통과
- 온채널·F온채널 실제 로그인 스모크 테스트 통과
- 주문 다운로드와 송장 등록은 스모크 테스트에서 실행하지 않음
