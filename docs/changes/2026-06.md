# 2026년 6월 변경이력

## 2026-06-23 — 시스터 송장 자동 업로드 운영 API 전환

### 요청 원문

> 인트라넷에서 출고한 시스터 업로드용 엑셀이 수동 업로드와 order-worker 자동 업로드 모두 안 된다. 업로드 후 구매자 채팅 송장 안내도 확인해줘.

### 결과

- 시스터 송장 자동 업로드 기본 주소를 localhost가 아닌 운영 도메인 API로 변경했다.
- 송장 업로드 요청에 주문서 다운로드용 서버 토큰도 함께 전달해 운영 서버 인증 불일치를 해소했다.
- 시스터 Vercel 프로젝트에도 동일 서버 토큰이 암호화 환경변수로 등록되도록 정리했다.
- HTTP 오류 시 시스터 API의 실제 오류 메시지를 로그에 표시하도록 개선했다.
- 로컬 `.env`의 송장 업로드 주소도 운영 도메인으로 변경했다.
