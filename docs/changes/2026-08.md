# 2026-08 변경 이력

## 2026-08-12 도매의신 송장 처리 응답 확인 보강 및 실업로드

### 요청 원문

인트라넷 > Add Data > 송장업로드 및 가송장 업로드에서 지난번 수정 후에도 도매의신 업로드가 실패한다. 오늘 업로드 대상 김인숙 010-6759-7059 1건이 있으므로 수정하고 실제 업로드까지 테스트해도 된다는 요청.

### 결과

도매의신 송장 등록 폼은 처리 후 빈 업로드 화면으로 돌아가므로 최종 화면 본문만 읽던 기존 자동화가 실제 성공 안내를 놓치는 것을 확인했다. 업로드 POST 응답 본문과 브라우저 알림을 함께 판독하도록 수정하고 HTML·스크립트 응답을 안전하게 텍스트로 정규화했다. 김인숙 주문 20260811183646280의 롯데택배 송장 255986504686을 실제 업로드하여 대상 1건, 확인 1건, 실패 0건을 확인했다. 도매의신 배송준비주문은 1건에서 0건으로 변경됐고 인트라넷 주문에는 벤더송장업로드완료 표식이 저장됐다.
