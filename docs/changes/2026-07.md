## 2026-07-08 프로젝트 변경 - Railway order-worker 배포 설정 추가

> 좋아.그러면 지금 order-worker  가 하는걸 그데로 레일웨이에 올려서 할수있도록 해줘.

### 결과

order-worker를 Railway GitHub Repository 서비스/Cron으로 배포할 수 있도록 Docker 기반 배포 설정을 추가했다. Playwright Chromium이 포함된 공식 Python 이미지를 사용하도록 `Dockerfile`을 만들고, Railway가 Dockerfile 빌드를 사용하도록 `railway.json`을 추가했다. 같은 이미지에서 `ORDER_WORKER_TASK=collect`이면 주문서 수집, `ORDER_WORKER_TASK=invoices`이면 송장번호 업로드가 실행되도록 Railway 엔트리포인트를 추가했다.

Railway 런타임에서는 다운로드/아카이브/로그/락 파일이 기본적으로 `/tmp/order-worker` 아래에 생성되도록 config 기본 경로를 조정했다. 장기 파일 보관이 필요하면 Railway Volume을 붙이고 `ORDER_WORKER_RUNTIME_DIR=/data/order-worker`로 바꾸면 된다.
