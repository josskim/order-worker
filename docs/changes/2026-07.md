# 2026-07 변경 이력

## 2026-07-02 프로젝트 변경 - 시스터 주문서 운영 export API 사용

### 요청 원문

> order-worker 주문서 자동 등록에서.. sister 는 에러나서 주문서 등록이 안되는데. .현재 시스터>조원 에 주문서가 있으니까..등록 되도록 수정해줘.
>
> HTTPConnectionPool(host='localhost', port=3000): Max retries exceeded with url: /api/seller/orders/export (Caused by NewConnectionError("HTTPConnection(host='localhost', port=3000): Failed to establish a new connection: [WinError 10061] 대상 컴퓨터에서 연결을 거부했으므로 연결하지 못했습니다"))

### 결과

시스터 주문서 export 기본 URL이 로컬 개발 서버 `http://localhost:3000/api/seller/orders/export`로 되어 있어, 로컬 시스터 서버가 꺼져 있으면 주문서 다운로드가 실패했다. 기본 URL을 운영 시스터 API `https://prahashop.co.kr/api/seller/orders/export`로 변경해 order-worker가 현재 시스터 조원 주문서를 운영 서버에서 직접 다운로드하도록 수정했다. `.env.example`에도 같은 URL을 명시했다.

### 변경 파일

- `order_worker/config.py`
- `.env.example`
- `docs/changes/2026-07.md`
