Stay 재고 워커는 기존 `TELEGRAM_*` 예약 봇을 계속 사용한다. 새 인트라넷 봇에서 연결 완료 메시지 전송을 확인했다. Hermes 이름의 실행 프로세스, 예약 작업, 시작프로그램, 프로젝트 설정 참조는 발견되지 않았다.
