## 2026-11-06 KST · 상품일괄등록 대기와 워커 잠금 복구

- 요청: 상품일괄등록 45분 초과의 원인을 확인하고 실행 이력에 상품일괄등록을 표시하며 실제 등록을 확인한다.
- 원인: 비정상 종료된 로컬 워커의 잠금 파일에 남은 PID를 다른 프로그램이 재사용하여 워커가 중복 실행으로 판단하고 시작하지 못했다. 45분 실패 작업은 시작되지 않았다.
- 변경: Windows에서 잠금 생성 시각보다 프로세스 시작 시각이 뒤인 PID를 재사용된 오래된 잠금으로 판별한다. 확인된 기존 잠금은 별도 파일로 보존 이동하고 로컬 디스패처를 재시작했다.
- 파일: `order_worker/lock.py`, `tests/test_lock_reused_pid.py`. 이력 표시 수정은 인트라넷의 기존 미배포 변경에 포함되어 있다.
- 검증: 잠금 및 상품등록 단위 테스트 6개와 인트라넷 이력 표시 검사 통과. G127144 대기 작업의 실제 실행 및 사이트별 결과를 확인 중.
- 커밋/배포: 수행하지 않음.
